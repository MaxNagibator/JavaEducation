# MultyThreading

Учебный проект: создаёт большой массив псевдослучайных чисел и сравнивает его
суммирование в одном потоке и через фиксированный пул потоков.

Для суммы используется `long`, потому что результат большого массива может не
поместиться в `int`.

## Запуск из IntelliJ IDEA

1. Открыть папку проекта.
2. Дождаться импорта Maven.
3. Запустить `Main.java`.

По умолчанию создаётся 50 000 000 чисел, а количество потоков равно числу
доступных процессоров.

Аргументы программы:

```text
<размер массива> <количество потоков>
```

Например, 100 миллионов чисел и 8 потоков:

```text
100000000 8
```

## Запуск из терминала

```powershell
mvn clean package
java -jar target/multythreading-1.0.0.jar 100000000 8
```

## Важное наблюдение

Суммирование массива часто ограничено скоростью оперативной памяти. Поэтому
увеличение числа потоков не гарантирует линейного ускорения, а на небольшом
массиве многопоточный вариант может оказаться медленнее из-за создания пула и
синхронизации.
